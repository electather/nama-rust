## Built-in Plugins

- **Load the `rust-crates` skill** before you change a Plugin. It says how to write, check and review Rust here.
- A Built-in Plugin depends on no workspace crate except `nama-plugin-api`, which brings the contract's messages. An Installed Plugin (a `cdylib`, such as `radarr` or `telegram`) depends on none except `nama-pdk` (which brings the contract's messages from `nama-plugin-proto`) and the shared libraries here, such as `servarr`, and a shared library follows the same rule. That way the compiler keeps them out of Kernel internals (ADR 0006). A Plugin never depends on another Plugin, and nothing here depends on `nama-server`.
- **A folder whose `Cargo.toml` has `crate-type = ["cdylib"]` is an Installed Plugin, bundled in the Server** unless its `Cargo.toml` says `bundled = false` under `[package.metadata.nama]`, as `template` does. Adding a Plugin is adding its folder: `crates/nama-server/src/plugins/wasm/bundling.rs` (shared by `build.rs` and the Server's tests) and `.github/scripts/wasm-packages.sh` read the folders.
- **An Installed Plugin logs through `nama_pdk::{debug!, info!, warn!, error!}`, and never logs a setting's value, a token or a response's body:** the Server blanks a secret only as it is stored (ADR 0061).
- **A Plugin that talks to a remote service tests its conversation in its own crate**, calling its Extension Point methods through `nama_pdk::testing` with the service's answers scripted or an in-process fake of it, such as `plugins/s3/src/fake_s3.rs`, never the network or real credentials (ADR 0065).
- **A Plugin tests its own settings** (keys, kinds, defaults) against its Manifest in its own crate, so the Server's tests need no edit for a new one.
- A Plugin's package is `nama-plugin-<folder>`, and a shared library's is not, such as `nama-servarr`. The Server's tests tell them apart by it.
- **Every Plugin ships a logo** (a shared library doesn't): a `logo.svg` next to its `Cargo.toml`, embedded with `include_str!` as its Manifest's `logo_svg`. It must read on a light and a dark tile alike, since an image can't follow the colour scheme.
