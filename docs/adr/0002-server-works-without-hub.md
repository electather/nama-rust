# A Server works fully without the Hub

A Server must be completely usable on a LAN with no Hub account and no internet connection. The Hub adds identity, Server discovery and a copy of Watch State, and is never required for playback, browsing or Requests. People dislike Plex largely because its server depends on plex.tv: you need an account, and you're locked out when it's down. The Hub never carries media bytes; that job belongs to the optional Relay.
