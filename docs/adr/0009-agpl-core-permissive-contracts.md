# AGPL-3.0 for the services, MIT/Apache-2.0 for the contracts

The Server, Hub and Relay are AGPL-3.0, so nobody can run a closed fork of the Hub as a paid service. The `proto/` schema, the generated client libraries and the plugin development kit are dual-licensed MIT/Apache-2.0, so third-party apps and Plugins can use any license they like.
