# Local Users, optional Hub Accounts, and how Watch State syncs

Every Server has its own Users, who work offline. A User can optionally be linked to a Hub Account. Only linked Users get Watch State sync, remote discovery, Watchlists and recommendations (unlike Plex, which requires an account to use the server at all). Each Server is the source of truth for anything watched on it and pushes every change to the Hub. The Hub keeps a merged copy for each Account, and per title the most recent timestamp wins. A Server pulls that copy when a User is first linked and after a rescan, which is how Watch State survives moving or rebuilding a Library. The Hub keys Watch State by external metadata IDs (TMDB, or TMDB/TVDB plus season and episode), never by Server-internal IDs. Unmatched items never leave their Server.
